How each structure is built:

- **Slab.** The rhombohedral cell is converted to the conventional hexagonal cell and rotated rigidly so that a₁ lies along x. It is cut between two O layers, which gives Al₂₍ₙ₋₁₎O₃ₙ per 1x1 cell with a charge of −6. Each terminal O then gets one H. The result is the fully hydroxylated (gibbsite-like) termination at 15.0 OH/nm² per face, neutral, periodic in-plane only (`pbc = T T F`). Interlayer spacings are the bulk values, not relaxed.
- **Oligomer.** It is a generic stand-in for the polydopamine-type layer, whose true structure is debated (R4). The SMILES and InChIKey are in its metadata. xtb refinement was not run because `~/.nacre-envs/xtb` does not exist; it was not created.
- **Hydrated Ca²⁺.** The shell directions come from a seeded 1/r repulsion on a sphere, so CN 6 gives an octahedron and other CNs are supported. Each water's dipole points away from the ion. CN and the Ca–O distance are drawing parameters, not results.
- **ACC.** Ca²⁺ and rigid CO₃²⁻ are inserted alternately in a sphere under minimum-distance rules. The cluster is anhydrous (see outstanding actions).
- **Total charge.** It is the formal oxidation-state sum, except for the oligomer, where it is RDKit's formal-charge sum. The smoke assembly is +2 because it shows one Ca²⁺ without a counter-ion.

## 2c Scene system (`figures/blender/`)

- **Command:** `blender -b --threads 4 -P figures/blender/scene.py -- --scene <name> --out <path>`. The wrapper `figures/blender/render.sh <scene> <out>` runs the R10 memory check first (20 % threshold, waits of 5 minutes, BLOCKED after 30 minutes). It then times the render with `/usr/bin/time -l` and writes `<out>.run.txt`.
- **`config.py`.** It has no Blender imports, so tests use it directly. It holds:
  - the render-settings loader;
  - the scene-config parser and validator;
  - the palette loader (`linear_rgb` only; an entry without it is refused);
  - a minimal extxyz reader, tested against ASE;
  - component filtering;
  - bond finding (distance below 1.15 × the sum of covalent radii, with an element-pair whitelist).
- **R7.** Any key matching text, label, arrow, annotat, caption, legend or font, anywhere in a scene config, is refused. Before rendering, `scene.py` also refuses any object type other than mesh, camera or light.
- **`geometry.py`.** Numpy mesh templates. Atoms of one element are merged into one mesh, and each bond is two half-cylinders coloured by the atom at each end.
- **Styles.** Ball-and-stick: spheres at 0.28 × the vdW radius, bonds of radius 0.14 Å. Space-filling: spheres at 1.0 × the vdW radius, no bonds. The radii come from `figures/blender/elements.yaml`, generated from `ase.data` by `build_elements.py`; a test checks it against the generator.
- **Camera.** Orthographic, framed on the projected extent of all spheres. The scene config sets the viewing direction, the up vector and the margin.
- **Rig (`rig.py`, defined once and used by every scene).** It has three disk area lights placed in the camera frame:
  - key at azimuth −35°, elevation 40°, irradiance 4.0;
  - fill at 50°, 10°, 1.4;
  - rim at 170°, 35°, 2.5.

  Light distance is 3 × the subject extent, and power scales with distance squared, so the lighting is the same at any scene size. A uniform white world at strength 0.35 adds ambient light; it is not seen because the film is transparent.
- **Render settings (`render.yaml`):**

  | Setting | Value |
  |---|---|
  | Engine | Cycles on CPU, 4 fixed threads |
  | Samples | 64 by default; scenes may override |
  | Seed | 0, not animated |
  | Adaptive sampling | off |
  | Denoiser | OpenImageDenoise |
  | Max bounces | 4 |
  | View transform | Standard, look None, exposure 0, gamma 1 |
  | Background | transparent film |
  | Output | PNG, RGBA, 8-bit, zlib level 100 (lossless) |

  The Standard view transform applies no filmic curve, so palette colours are not shifted.
- **PNG metadata.** Stamp and metadata fields are switched off. Cycles still writes its render timings into PNG text chunks, so `scene.py` removes the `tEXt`, `zTXt`, `iTXt`, `tIME` and `eXIf` chunks afterwards. Image data is copied unchanged, nothing is re-encoded, and CRCs are checked.
- **Reproducibility:** two renders of the smoke scene gave byte-identical PNGs (sha256 `a428d2a2…`). Before the chunk removal, the pixels were already identical and only the timing text differed.
- **Scene configs:** `figures/blender/scenes/*.yaml`. On day 1 there is `smoke.yaml`. The parser caps resolution at 1920 × 1080 pixels.

## Fix-up (integration)

The bytes of `structures/preprint/catechol_oligomer.extxyz` therefore varied by machine, and `test_committed_files_regenerate_bit_for_bit` failed wherever the environment existed.

**Change.** The environment lookup and the `xtb_refinement` key are removed from the oligomer builder. Metadata is now limited to builder, parameters, seed, locked library versions, source ids and geometry-derived values. No refinement is applied on day 1; if one is added later it is requested by parameter and the file records that it was applied and the pinned tool version. Tool availability belongs to this report only: `~/.nacre-envs/xtb` is absent on the day-1 machine and present on the integration machine. This supersedes the earlier statement that the file's metadata says `xtb_refinement: not run`.

**Other builders checked.** slab, water, ion, acc and assemble write only deterministic values (parameters, seed, locked library versions, source ids, counts). The fetch timestamp lives in the source cache `sources/al2o3_corundum.json`, which is not part of the structure files. No other leaks found.

**Tests added.** `test_bytes_do_not_depend_on_xtb_environment` rebuilds all structures under a temporary HOME with and without `.nacre-envs/xtb` and compares hashes to the manifest. `test_no_machine_dependent_text_in_committed_files` scans the committed files for repository and home paths, hostname, user name, `xtb` and timestamps.
