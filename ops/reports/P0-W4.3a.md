## 3f. Retrodiction entry point (`src/nacre/screen/retro.py`)

- **Call.** `run_cases(cases_path, params_path=None, draws=20000, seed=0, n_perm=1000, criterion_path=None)` returns the `retro-results/v1` record of SCHEMA.md §5. It writes nothing and was never run on `preprint/retrodiction/cases.yaml`.
- **Interfaces (N11, D17).**
  - Crystal–template adhesion (`dG_bind` or `E_int` per contact area, or `W_adh`) maps to γ_sn by Dupré: cos θ = W/γ_nl − 1.
  - Ca²⁺ binding (`c_local` with Γ_s and δ_s, or `Delta_G_seq`) maps to γ_sl by Gibbs–Langmuir: cos θ = cos θ₀ + Δγ_ads/γ_nl, with the Ca-free contact a shared nuisance.
  - OWRK components map to γ_sl.
  - γ_net maps to f = (γ_net/γ_nl)³.
  - Any `Omega_local` mapping is refused; Ω is the pair's bulk Ω.
  - Units go through the units module; `kT` is resolved with the pair temperature.
- **Outputs.** Per-case barriers in k_BT, Δ with its median and 90 % interval, p_test_higher, boundary mass and the criterion verdict (undetermined counts as a miss).
- **Swap check.** Test and reference are exchanged on the same draws, and Δ must change sign exactly, draw by draw. In the OWRK mapping, the frozen nuisance cos θ_ref is anchored on the reference surface; it is turned into a shared γ_sn draw before any barrier is computed, so the barrier code sees one surface plus shared draws.
- **Permutation null (cp3 R9, descriptive).** Test-surface inputs are reassigned among cases with the same mapping; the distribution of correct counts and P(X_perm ≥ X_obs) are reported. The constant-predictor baseline is not implemented, because R9 drops it.
- **Also reported.** k from the binomial rule (12 cases give k = 10), the conclusive-only tally and the study-level tally.
