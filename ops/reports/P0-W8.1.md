**lint-numbers** (`nacre preprint lint-numbers`):

- **Files checked:** `main.tex`, `sections/`, `si/` and `captions/`. Captions are checked like text.
- **Order per line:**

  2. Remove the allowlisted forms, in file order: the f(theta) shape factor, 16 pi / 3, 4 pi / 3 and 4 pi; `\ce{}` formulae; ion charges; single-digit exponents and subscripts.

## Fix-up (integration)

### Defects

- **D1.** `preprint/generated/{front,authors,credit}.tex` were committed with headers embedding the git blob sha of the whole `ops/tracks/p0.yaml` and `p0_authors.yaml`, so every ledger commit made `test_committed_generated_files_are_up_to_date` fail. `numbers.tex` carried per-result-file blob shas and would have failed the same way when a result changed.
- **D2.** `si/main_si.tex` inputs `theory/derivation_body.tex`, which uses macros such as `\Rs` from `theory/macros.tex`; neither document loaded `theory/macros.tex`, so the draft build failed once `theory/` was present.

### Changes

- `front.tex`, `authors.tex`, `credit.tex`, `declarations.tex` and `numbers.tex` are build-time artefacts: untracked (`git rm --cached`), listed in `preprint/generated/.gitignore`, and written by `nacre preprint prepare` and by build.sh (draft and release) through the new `build.generate`. `sources.yaml` and `mock/` stay tracked.
- Provenance headers name the consumed fields and carry a digest of only the consumed values (title; author fields per author in order; CRediT fields; declaration fields; each macro's source, key, format, unit and read value). No whole-file blob sha remains. Editing an unconsumed part of a ledger, register or result file leaves the output byte-identical.
- Release mode is unchanged: it still fails on TBD, placeholders, mock macros and a missing AI include.
- `test_committed_generated_files_are_up_to_date` and `test_committed_numbers_tex_is_up_to_date` are replaced by tests for byte-determinism, unconsumed changes (ledger, register, result file, sources.yaml schemas block) leaving output unchanged, consumed changes altering exactly the expected files, headers without blobs, files git-ignored and untracked, stale or missing files replaced by `generate`, build.sh preparing before latexmk, and the real draft build regenerating deleted files. `copy_tree` in the test helpers now skips the ignored files and regenerates them.
- `main.tex` and `si/main_si.tex` load `../../theory/macros.tex` through `\IfFileExists` right after `numbers`, before any section or theory input; the derivation input stays conditional.
