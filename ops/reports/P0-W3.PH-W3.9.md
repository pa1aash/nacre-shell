## Registered form
Reference of a hydrated amorphous phase A: the crystalline phase or phases C of the same Ca:P (and OH, HPO4) composition plus n_hyd liquid water at a_w = 1; Delta_G_gc_w = G(A) - G(C) - n_hyd mu_w(l, a_w = 1) >= 0 (A is metastable against C plus water). E_ub(A) = E_ub(C) - [Delta_G_gc_w - n_hyd R T ln a_w]/(Delta_n_Li F) <= E_ub(C). The sign bound is exact, so the amorphous row uses the margin of its crystalline reference row and the sink reference state of Section 2h unchanged. It falsifies only.
