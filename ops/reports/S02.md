## Deviations and decisions

1. **Packet content.** `nacre gate --packet` (in `src/nacre/cli/commands/gate.py`, outside the lane)
   writes only the layer A summary and has no hook for gate-specific sections. The lane-owned
   `charter/packet.py` appends the charter sections after a marker, and is idempotent. Rerunning
   `nacre gate G0 --packet` alone drops those sections; rerun `charter/packet.py` after it.
2. **Environment flake.** macOS keeps re-setting the `hidden` flag on `.venv/.../*.pth` (mtimes
   unchanged; likely Desktop file syncing). This intermittently breaks `import nacre`, and it caused
   8 spurious failures in one suite run inside `--packet`. Every gate and verify run of record used
   `chflags -R nohidden .venv` and `PYTHONPATH=<worktree>/src`.
3. **Commit ordering slip.** The two charter commits (244bcb9, 0bccfdd) were made in a command chain
   whose test step's failure was masked by a pipe. That run had collection errors from the flake in
   item 2. The same tree then passed the full suite (119 passed) before any further commit. History
   was not rewritten.
4. **Deck values.** The only numbers in the charter are quoted from the deck and labelled with their
   slide (the C3 bands, the near-0.5 disclosure, the 4 V bound in R-cell). None is typed from
   literature or computed.
