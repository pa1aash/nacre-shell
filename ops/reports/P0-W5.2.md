## Task B: R-slurry Pourbaix, final for params 680a44b

**Question.** At the regime pH and potential, and at each design point's bulk Ca2+ activity and dissolved carbonate:

- is calcite (or ACC) the equilibrium state of Ca and C(IV)?
- how far above that equilibrium does it sit?
- is a native Al oxide the equilibrium state of Al?

These are equilibrium proxies; no rate is implied.

**Axes.**

- pH from `ph_slurry` (10.0 to 13.0, 31 points).

This gives 18 design points, one schema v2 document each, in `results/preprint/pourbaix/final/slurry/`. The summary is `final/slurry_summary.json`.

**Construction.**

- **C(IV) carbon.** Carbon is held in the C(IV) carbonate system. The regime fixes a_CO3 (G0 fix F2), and the regime potentials lie below the carbonate/CH4 couple. Reduced carbon is reported as a labelled sensitivity: with carbon redox allowed, calcite lies above its edge on 81 to 85 % of the region, by up to 1.58 eV/atom. That is thermodynamics only; carbonate reduction is not a rate claim.
- **Speciation.** Closed-system speciation is exact for each pH column (ideal solution).
- **Domain map.** The domain map uses the predominance convention.

**Results.**

- **Domains.** Over the whole region, at every design point, the state is Al(OH)4[-] + CaCO3(s). No Al-Ca or Al-C compound is stable.
- **Calcite.** Decomposition energy 0 eV/atom at every design point and grid point (edge e_f = 0.0495 eV/atom).

## Task E: P0 dispatch (`jobs/preprint/`, ruling B5)

**Design.**

- `dispatch.py` defines a transport interface (`put`, `get`, `run`) with two implementations:
  - `LocalTransport`: a directory plays the pod;
  - `SSHTransport`: ssh/scp with keep-alive and BatchMode, parsing the provider's SSH string.
- The pipeline:
  1. pin the commit;
  2. `git archive` it and record the tar's sha256;
  3. sync, verifying the tar hash on the pod;
  4. launch with tmux, `p0-<run_id>`;
  5. `remote/run_job.sh` writes a heartbeat, installs the pinned packages at job start into a job-local venv (`install.log`), runs the job, and writes `manifest.json` (sha256 per output) and `status.json`;
  6. wait (stale-heartbeat detection);
  7. hash-verified collection;
  8. one ledger line.

**Ledger format.** No S31 format is documented in the repository (searched `ops/`, `jobs/` and `src/`). The format is defined as `p0-dispatch/1` in `jobs/preprint/README.md`.

**tmux.** The laptop has no system tmux. tmux 3.7b comes from a user-level conda-forge env (`jobs/preprint/envs/tmux_env.yaml`, `~/.nacre-envs/tmux`).

**Dry run** (local transport, no SSH, commit `d7e407c`, run `dryrun-probe-d7e407c`): state done, exit 0, 6 heartbeats, `six==1.16.0` installed pinned and logged. Every output was hash-verified, and the ledger line has 7 outputs under `results/preprint/anchor/dispatch/`.
