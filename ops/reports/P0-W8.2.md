### Bibliography build issues found and handled

The draft build first failed on the fetched entries. Neither the pinned template nor the fetched entries were edited.

1. **No pages.** `rsc.bst` stops bibtex when an article with a volume has no `pages`. Crossref gives no pages for four article-number entries: heidbuchel2022enabling, schmidt2024myriad, li2018apparent and maffre2025buffer.
2. **`&amp;`.** Crossref writes "Crystal Growth &amp; Design", and TeX reads `&` as an alignment tab.
3. **Unicode pdflatex cannot set.** Decomposed accents (U+0301), U+2010 HYPHEN and γ.

The fix is a new module, `src/nacre/preprint/refs.py`, which `prepare` calls:

- It refuses any `\cite` key that has no `refs.bib` entry. This also runs as the new subcommand `nacre preprint cites`.
- It writes the build-time copy `build/bib/refs_build.bib` with these changes:
  - HTML entities decoded and bare `&` escaped;
  - accents composed (NFC);
  - mapped characters written as TeX;
  - `pages={\nacreMissing{article number}}` added where pages are absent.
- An unmapped character stops `prepare` and names the character.
- `main.tex` and `si/main_si.tex` read `\bibliography{refs_build}`. `build.sh` sets `BIBINPUTS` to `build/bib` only, so `paper/refs.bib` is never searched; latexmk puts the source directory ahead of `BIBINPUTS`, hence the distinct name.
- A draft shows a red "[pending input: article number]" in those four references. The release guard lists them, and the LaTeX layer stops a release on the marker.
