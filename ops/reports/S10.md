# Session report: S10

Retrieval toolkit (Phase 1 tooling). Lane a-retrieval, branch lane/a-retrieval, window A2.

## Built

- **Shared HTTP layer** (`src/nacre/retrieval/http.py`). One `requests` session; User-Agent with a mailto contact read from `configs/retrieval/contact.yaml`; per-source minimum request intervals and timeouts from `configs/retrieval/sources.yaml`; exponential backoff with jitter on 429 and 5xx, honouring `Retry-After` (seconds or HTTP date); a raw-response cache under `lit/corpus/cache/` keyed by a hash of method, URL, parameters and body. Error responses are never cached. 404 maps to `not_indexed`, other 4xx to `http_error`, exhausted 429 to `rate_limited`. TLS verification failures are not retried and verification is never disabled.
- **Nine source clients**, one module each, returning normalised records: crossref, unpaywall, semanticscholar (search, lookup, references, citations), arxiv (Atom parse; PDFs into the local cache only), chemrxiv, openaire (publications and datasets), zenodo, wayback (snapshot lookup, returns a snapshot dict rather than a bibliographic record), lens (patents; without `LENS_TOKEN` every query writes a `no_token` gap row and returns empty with no request made).
- **Normalised record** (`record.py`): source, source_id, doi (lower-case, prefix-stripped, validated), arxiv_id, title, authors (family, given, orcid), year, venue, type, oa_status, licence, urls, retrieved_utc, raw_cache_key. Abstracts and full text are never read into committed fields.
- **Corpus store** (`store.py`) writing `lit/corpus/records.jsonl`: dedupe by exact DOI, then arXiv id, then normalised title plus year (title matching is blocked when the two records carry conflicting DOIs or arXiv ids); provenance from every source merged into a `seen_in` list; `fulltext_sha256` recorded when a full text is cached. Only committed fields are ever written, so an abstract or text key cannot reach the file.
- **Gap ledger** (`gaps.py`, `lit/instrument_gaps.csv`): columns utc, source, query_or_id, failure_kind, detail; every client writes a row on any coverage failure.
- **CLI** (`cli.py`, auto-discovered): `nacre retrieve search | doi | fulltext | gaps | stats`.
- **Dependency:** `requests` added to `pyproject.toml`; `uv.lock` regenerated. Added a `network` pytest marker, excluded by default (`addopts = "-m 'not network'"`).
- `lit/corpus/.gitignore` excludes `cache/` and `fulltext/`. `records.jsonl` is committed empty: nothing from the smoke or CLI trials was kept in the corpus.
